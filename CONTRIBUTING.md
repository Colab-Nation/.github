# Contributing to CoLab Nation

Thank you for your interest in contributing to **CoLab Nation**! 

## Our Philosophy: Proof over Paper
We value hands-on engineering, clean documentation, robust automated testing, and respectful collaboration.

## Contribution Workflow
1. **Fork the Repository**: Clone to your local machine and create a descriptive feature branch (`feat/your-feature` or `fix/issue-description`).
2. **Write Clean Code**: Follow clean code principles, write unit and integration tests, and adhere to the project's linter configurations.
3. **Sign-off Your Commits**: All commits must include a Developer Certificate of Origin (DCO) sign-off:
   ```bash
   git commit -s -m "feat(scope): concise description"
   ```
4. **Open a Pull Request**: Provide a clear PR description detailing your changes, motivations, and testing verification.

## Community Code of Conduct
We are committed to providing a friendly, safe, and welcoming environment for everyone, regardless of background or experience level.
