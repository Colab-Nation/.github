# Security Policy

## Supported Versions
We actively maintain and provide security patches for the latest releases across all CoLab Nation repositories.

## Reporting a Vulnerability
If you discover a security vulnerability within any CoLab Nation project, please send an email to **chilkotikartik@gmail.com**.

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce the issue or a proof of concept
- Any potential mitigations you have identified

We appreciate your responsible disclosure and will acknowledge reports within 48 hours.
